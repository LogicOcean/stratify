# Code of conduct

This project follows the [Rust Code of Conduct](https://www.rust-lang.org/policies/code-of-conduct).

In short: be kind and be direct. Criticism of code is welcome and expected;
criticism of people is not. Assume the person you are replying to is acting in
good faith and is short on time.

Report anything that needs attention to the repository owner through
[GitHub's private vulnerability reporting](https://github.com/LogicOcean/stratify/security/advisories/new)
or a direct message. Reports are handled privately.
